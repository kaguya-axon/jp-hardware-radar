# JP Hardware Deal Radar

日本高端硬件捡漏与比价工作台（Mercari · Yahoo!オークション · Yahoo!フリマ · 日本中古店 / Apple 官翻）。

- **前端工作台**：纯静态单页应用，托管于 GitHub Pages 并支持 Google Sites 整页嵌入。
- **实时数据源**：`data` 分支下的 `deals.json`，由家庭 Ubuntu NAS 上的轻量监控服务定时抓取并推送同步。
- **主要特性**：
  - 自动排除黑名单型号（如 `Intel X540-T2`）
  - 计算预计日本到手价（日元 + 人民币折算）并与国内闲鱼价格对比
  - 未知属性严格标注「待核实」，自动生成日语询价与砍价模板
  - 多维筛选、比价表格、横向参数对比与本地跟进日志
